## How it works

Workers access a bucket through a binding; everything else uses the S3 API with access keys. Buckets can have custom domains, event notifications to Queues, lifecycle rules for expiry, and presigned URLs for direct uploads from a browser. The photoproof.io case study is built on R2: uploads and downloads go straight to object storage at the edge.
